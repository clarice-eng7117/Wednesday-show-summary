# TV Show Analysis: *Wednesday* (Netflix)

This repository contains a structured data report on the viewership and critical reception of the Netflix original series *Wednesday*. The project fulfills the requirements for the Generative AI and Data Visualization assignment.

## 📄 Project Overview
The report analyzes the "sophomore slump" phenomenon by comparing Season 1 and Season 2 metrics. It highlights how creative quality (ratings) can improve even when viral viewership numbers normalize.

### Key Features:
* **Digital Book Design:** Rendered in a responsive HTML format with a floating Table of Contents.
* **Data Visualizations:** Includes viewership trends and episode-to-episode engagement graphs.
* **Mathematical Analysis:** Uses LaTeX for quality index calculations and percentage change metrics.

## 🛠️ Tech Stack & Tools
* **Language:** R (RMarkdown)
* **Output Format:** HTML (Optimized for web browsing)
* **Version Control:** Git/GitHub
* **Calculations:** Assisted by Generative AI (Gemini) to ensure statistical accuracy.

## 📂 File Structure
* `report.Rmd`: The source code for the analysis.
* `report.html`: The rendered digital report (Open this file in a browser to view).
* `graph-season.png`: Visualization of season-by-season reach.
* `graph-ep-to-ep.png`: Visualization of audience engagement per episode.

## 🚀 How to View the Report
1. Clone this repository.
2. Open `report.html` in any modern web browser (Chrome, Safari, or Edge).
3. Use the floating sidebar on the left to navigate between sections.
